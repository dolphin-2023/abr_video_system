# 本地数据目录

此目录用于存放从原始发布方下载的原始数据集。原始数据不会被提交到 Git。

请按照 [`trace_tools/README.md`](../trace_tools/README.md) 中的说明，将文件放入 `data/raw/` 目录。
在下载或处理数据前，请查阅各数据源的许可证或使用条款。

---

# Local Data Directory

This directory is reserved for raw datasets downloaded from their original
publishers. Raw data is intentionally excluded from Git.

Place files under `data/raw/` as described in
[`trace_tools/README.md`](../trace_tools/README.md). Review each source's
license or terms of use before downloading or processing it.
